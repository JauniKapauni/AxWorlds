# AxWorlds
> Minecraft plugin to create and manage custom worlds
---
## Features
- Create World
- Remove World
- List Worlds
- Teleport to world
---
## Installation
1. Download the latest release
2. Put the `.jar` into the `/plugins` folder of server
3. Start the server
